## 三、硬件设计

### 3.1 定时器 → 蜂鸣器映射

```
         APB2 总线                      APB1 总线
  TIM1 (64MHz) → PA3  ─── Buzzer #1    TIM2 (72MHz) → PA1  ─── Buzzer #2
  TIM8 (64MHz) → PB5  ─── Buzzer #8    TIM3 (72MHz) → PA0  ─── Buzzer #3
                                        TIM4 (72MHz) → PA6  ─── Buzzer #4
                                        TIM5 (72MHz) → PA7  ─── Buzzer #5
                                        TIM6 (72MHz) → PB0  ─── Buzzer #6
                                        TIM7 (72MHz) → PB1  ─── Buzzer #7
  SysTick (Cortex) → 1ms 系统时钟
```

> APB2 时钟 = 72MHz；APB1 时钟 = 36MHz × 2 = 72MHz（TIM2\~7 取 APB1×2 分频后波形）。所有定时器 PSC=72-1 统一 1MHz tick。

### 3.2 TIM6/TIM7 说明

TIM6 和 TIM7 是 **Basic Timer**——只有 ARR 和计数器，没有输出比较通道。不影响位翻转方案，因为我们用 `GPIO_SetBits/ResetBits` 而不是 `TIM_OCMode`。有 Update IRQ 就够。

### 3.3 编号规则

|   蜂鸣器编号   | 频率来源 | 声部角色      |
| :-------: | ---- | --------- |
| Buzzer #1 | TIM1 | 最高音（旋律顶线） |
| Buzzer #2 | TIM2 | 第二高音      |
| Buzzer #3 | TIM3 | 第三高音      |
| Buzzer #4 | TIM4 | 中高音       |
| Buzzer #5 | TIM5 | 中低音       |
| Buzzer #6 | TIM6 | 低音        |
| Buzzer #7 | TIM7 | 更低音       |
| Buzzer #8 | TIM8 | 最低音（贝斯底线） |

> `--voices N` 时使用前 N 路蜂鸣器（例如 `--voices 4` 仅用 #1\~#4），其余置空。

### 4.2 `audio_pwm.c` — 数组化重构

**当前状态**：硬编码 `v0_*` / `v1_*` / `v2_*` 三组变量，三个独立 ISR。

**目标状态**：**统一的** **`VoiceSlot`** **数组驱动**：

```c
#define NUM_VOICES  8

typedef struct {
    uint16_t   arr_high;
    uint16_t   arr_low;
    uint8_t    phase;
    uint8_t    active;
    TIM_TypeDef *tim;
    uint16_t   gpio_pin;
    uint8_t    irq_channel;
} VoiceSlot;

static VoiceSlot g_voice[NUM_VOICES] = {
    {0,0,1,0, TIM1, GPIO_Pin_3,  TIM1_UP_IRQn},   // #1
    {0,0,1,0, TIM2, GPIO_Pin_1,  TIM2_IRQn},       // #2
    {0,0,1,0, TIM3, GPIO_Pin_0,  TIM3_IRQn},       // #3
    {0,0,1,0, TIM4, GPIO_Pin_6,  TIM4_IRQn},       // #4
    {0,0,1,0, TIM5, GPIO_Pin_7,  TIM5_IRQn},       // #5
    {0,0,1,0, TIM6, GPIO_Pin_0 | GPIO_PinB_0,  TIM6_IRQn},  // #6 (PB0)
    {0,0,1,0, TIM7, GPIO_Pin_1 | GPIO_PinB_1,  TIM7_IRQn},  // #7 (PB1)
    {0,0,1,0, TIM8, GPIO_Pin_5 | GPIO_PinB_5,  TIM8_UP_IRQn}, // #8
};
```

**ISR 统一化**（每个定时器调用同一个回调）：

```c
static void _voice_isr(uint8_t idx)
{
    VoiceSlot *v = &g_voice[idx];
    if (TIM_GetITStatus(v->tim, TIM_IT_Update)) {
        TIM_ClearITPendingBit(v->tim, TIM_IT_Update);
        if (v->phase) {
            GPIO_ResetBits(EXTRACT_PORT(v->gpio_pin), EXTRACT_PIN(v->gpio_pin));
            v->tim->ARR = v->arr_low;
            v->phase = 0;
        } else {
            GPIO_SetBits(EXTRACT_PORT(v->gpio_pin), EXTRACT_PIN(v->gpio_pin));
            v->tim->ARR = v->arr_high;
            v->phase = 1;
        }
        v->tim->CNT = 0;
    }
}

void TIM1_UP_IRQHandler(void) { _voice_isr(0); }
void TIM2_IRQHandler(void)    { _voice_isr(1); }
void TIM3_IRQHandler(void)    { _voice_isr(2); }
void TIM4_IRQHandler(void)    { _voice_isr(3); }
// ...
```

改动量：\~120 行（删除 3×\~40 行硬编码+新增 \~80 行数组驱动+\~40 行 Buzzer #4\~#8 ISR）

### 4.3 Systick 替代 TIM4 为 1ms 时钟

TIM4 原本在 `audio_pwm.c` 中作为 1ms 全局计数器。现在 TIM4 要用于 Buzzer #4，所以 1ms 时钟全部迁移到 Systick。

`audio/main.c` 已有 `SysTick_Handler { g_ms++ }`，只需把 `audio_pwm.c` 中引用 `TIM4_IRQHandler` 的地方改为 `extern volatile uint32_t g_ms`（从 `main.c` 导出）。删除 `TIM4_Config()`。

改动量：\~5 行（audio\_pwm.c 中引用外部 `g_ms`，删除 TIM4\_Config）

## 五、IRQ 负载与优先级

### 5.1 最坏情况

```
8 路 × C7(2093Hz) × 2 flips = 33,488 IRQ/s
每次 ISR ≈ 30 周期 ≈ 0.42μs
CPU 占用: 33,488 × 0.42μs ≈ 14ms/s = 1.4%
```

> 实际音乐场景（多数路 ≤1kHz）：< 1%。

### 5.2 优先级

| 中断                                                            |  抢占 : 子  | 用途            |
| ------------------------------------------------------------- | :------: | ------------- |
| USART1                                                        |    1:0   | DMA 视频 / 串口命令 |
| TIM1\_UP / TIM2 / TIM3 / TIM4 / TIM5 / TIM6 / TIM7 / TIM8\_UP | 2:0\~2:7 | 8 路蜂鸣器        |
| SysTick                                                       |    3:0   | 1ms 系统时钟      |

## 九、后续扩展

- **16 路**：需要 STM32F407（14 个定时器，F103 无可行方案）
- **12 路**：F103 系列上限 8 路已到顶
- **DAC 方案**：需要外挂 DAC 芯片或使用 STM32 内部 DAC（但 F103 仅 2 路 12-bit DAC）
- **PCM 音频**：M4/M7 内核 + 外部 DAC + DMA（完全不同的架构）
